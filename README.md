# Learning Notes

这里整理并分享 **lim99913** 在课程学习与自学过程中形成的电子笔记。

仓库采用“一门课程一个目录”的结构。每门课程可以独立维护说明、成品讲义与配套图片，
便于今后持续加入新的学习笔记。

## 笔记目录

| 课程 | 主要内容 | 状态 |
| --- | --- | --- |
| [概率论与数理统计](./概率论与数理统计/) | 概率论基础、多维分布、极限定理、参数估计与假设检验 | 已更新至第七章 |

## 目录结构

```text
Learning-Notes/
├── README.md
├── LICENSE
└── 课程名称/
    ├── README.md       # 课程来源、内容与更新说明
    ├── Notes/          # 可下载的成品笔记
    └── assets/         # 封面及其他展示图片
```

公开分享的讲义默认采用水印版。每门课程的下载入口与使用说明请查看对应目录中的
`README.md`。

## 勘误与交流
