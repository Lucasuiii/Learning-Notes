# Learning Notes

这里整理并分享我个人在课程学习与自学过程中形成的电子笔记。

仓库采用“一门课程一个目录”的结构。每门课程可以独立维护课程说明、笔记、作业与测试资料，
便于今后持续整理学习内容。

## 笔记目录

| 课程 | 主要内容 | 状态 |
| --- | --- | --- |
| [概率论与数理统计](./概率论与数理统计/) | 概率论基础、多维分布、极限定理、参数估计与假设检验 | 已完结 |

## 目录结构

```text
Learning-Notes/
├── README.md
├── LICENSE
└── 课程名称/
    ├── README.md       # 课程来源、内容与更新说明
    ├── notes/          # 课程笔记与讲义
    ├── homework/       # 课程作业及解答
    └── test/           # 测验、试题及复习资料
```

每门课程的下载入口、目录说明与使用说明请查看对应目录中的`README.md`。
